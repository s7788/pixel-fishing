# pixel-fishing：實作素材包 v1

本包是 pixel-fishing（`pixel-fishing`）使用的 8-bit 路亞釣魚素材，包含三個白天場景、十二種魚、釣手與釣具、特效、漁獲與紀錄介面。repo 內的外掛已接入遊戲狀態機、漁獲數值生成、存檔與 Claude 工作回合連動；安裝與玩法見 [repo 說明](../README.md)。本文件說明素材格式與接入方式。

直接打開 **preview.html** 可切換場地、動作與魚種；**overview.png** 為總覽。主遊戲畫布是 384×216，背景圖層以 128×72 儲存、整數放大 3 倍。所有遊戲用 PNG 都採硬像素與二值透明度，背景底圖限 16 色，人物共用 24 色調色盤，魚體每張至多 16 色。

素材總覽提供[繁體中文版](overview.png)與[英文版](overview.en.png)。在 repo 根目錄執行 `npm run build:preview` 可重建預覽頁及兩種語言的總覽；互動預覽頁目前仍使用繁體中文。

## 檔案與接入方式

- `assets/`：正式尺寸的 RGBA PNG，可直接載入。
- `manifest.json`：每張圖的檔案、尺寸、透明邊界、錨點、圖集位置、動畫順序、影格時間與循環設定。
- `pixel-data.json`／`pixel-data.ts`：248 個非圖集素材的原生像素 RLE，供像素繪圖管線使用。四張圖集不重複輸出 RLE。
- `validation.json`：尺寸、透明度、調色盤、引用、錨點、圖集與 PNG／RLE 一致性檢查。
- `checksums.sha256`：252 張遊戲 PNG 的校驗碼。
- `generation-plan.json`、`repair-prompts.json`、`coast-ledge-prompt.json`：內建 image_gen 的完整提示詞與補做紀錄。
- `anchor-overrides.json`：人工檢視後修正的手掌握點。
- `tools/`：可重建輸出、預覽與檢查的素材整理工具。使用 Node.js 與 sharp；在 repo 根目錄執行 npm install 即可安裝依賴。

生成母圖使用 **內建 image_gen**，以已確認的 `concept-8bit-v2.png` 為風格參考；正式圖片再經切圖、整數像素對齊、調色與透明度標準化。簡單介面與竿線幾何使用整數像素繪製。此包沒有截取原參考專案的角色或場景作為遊戲素材。

### 場景圖層

`scenes.<id>.layers` 固定依序為：

1. `far`：天空、遠山等遠景。
2. `water`：水面與水體，和 far 共同還原背景。
3. `platform`：棧台、礁岩或完整船身，先於人物繪製。
4. `foreground`：和平台共用來源的下部遮擋，人物、釣具之後繪製。

前三層畫完再畫人物、釣竿、魚、釣線與特效，最後補上第四層。四個圖層都是 128×72，放大 3 倍。`scenes.<id>.feet` 與 `waterline` 是 **384×216 遊戲座標**；圖層檔案與各物件的 `anchors` 則是**該圖原生像素座標**。

### 角色與釣具

人物為 48×64。腳底錨點 `[24,62]` 放到場景的 `feet`，再用該格的 `anchors.grip` 對接釣具。每格 `equipment` 提供建議使用的釣竿或抄網 ID；`null` 表示該格不顯示手持釣具，例如起魚展示的最後一格、放流動作。

釣竿為 96×96，含 `grip` 與 `tip`；抄網為 64×64，含 `grip` 與 `basket`。預覽在船場景將釣竿以 0.8 倍顯示，讓高於水面的站位仍能容納整支竿；接入時可依鏡位調整。

**釣線由程式繪製**，不可烙入人物圖。用竿尖連到路亞的 `tie`，或用搏魚狀態連到魚嘴 `mouth`。鏡像魚時也要鏡像嘴部座標，不能只翻圖片。轉向影格可能面向左側，請使用每格的 `facing`，不要假設全部朝右。

### 動畫

釣手待機每格 250 ms，其餘每格 125 ms；魚游動每格 125 ms，轉向與躍水每格 150 ms；特效每格 100 ms。這些是素材建議時間，遊戲引擎可調整，但一次性動作請依 `loop:false` 播完並停格或轉狀態。預覽頁為了便於檢視會反覆展示全部動作。

魚的完整場內畫布：湖泊魚 48×24、其他魚 64×32；圖鑑側面圖 96×48、小圖與未解鎖剪影 24×16。路亞選單圖 32×16、場內圖 16×8。特效 48×32。

圖集擷取時使用 `sprites.<id>.atlas` 的 `x,y,w,h`，不要把所有魚都當成同樣大小。釣手圖集 4 欄、魚圖集 8 欄、特效 4 欄、路亞 3 欄。每格各自保有透明邊界與原生錨點。

### 重量與長度介面

圖片提供漁獲面板、最長紀錄圖示、最重紀錄圖示及數字／`cm`／`kg` 字圖；**魚名、長度、重量、日期與紀錄標記由程式動態填入**。`ui` 的 `nineSlice` 可供面板延伸，內距見 `contentPadding`。

字圖定位見 `fonts.measurements.glyphs`。繁中魚名與提示使用宿主字型；不從生成圖片辨識文字。

外掛已分別保存最長與最重漁獲紀錄，可能對應不同的魚；長度以整數 mm、重量以整數 g 儲存，顯示成一位小數 cm／兩位小數 kg。預覽中的 68.4 cm、3.26 kg 都是示意資料。

## 檢查範圍

素材保留權利，使用範圍見 [LICENSE.assets.txt](LICENSE.assets.txt)；repo 程式碼的 MIT 授權不包含本包像素美術。

已檢查 252 張遊戲用 PNG 的尺寸、RGBA、二值透明度、引用與圖集範圍；248 份 RLE 逐像素解碼後與 PNG 完全相同。九組釣手動作沒有重複的完整影格，握點／竿尖／魚嘴落在可見像素附近，三場地站位落在平台上。素材預覽以瀏覽器實際檢視湖泊、海岸、船上及動作切換。

這是低影格率的第一版像素素材；若擴充搏魚互動、魚體縮放、鏡像、抄網旋轉或張力表現，仍應依遊戲鏡頭調整演出。新增場景、魚種、服裝與夜景不包含在本版範圍。
