pixel-fishing is an 8-bit fishing companion for Claude Code. Send a prompt and the angler casts; a normal answer decides the catch and plays the landing and release animations.

![pixel-fishing gameplay](https://raw.githubusercontent.com/s7788/pixel-fishing/main/docs/media/demo.gif)

This release unifies the plugin, marketplace entry, pane, and commands under the pixel-fishing name.

## Install

Inside a Claude Code session (2.1.275 or later):

```text
/plugin install pixel-fishing --marketplace s7788/pixel-fishing
```

From a shell (2.1.292 or later):

```bash
claude plugin install pixel-fishing --marketplace s7788/pixel-fishing
```

After loading the plugin, open `/pixel-fishing` or try `/pixel-fishing-demo` twice to cast and reel in without a model turn.

## Included

- Three rotating spots: lake, coast, and boat.
- Twelve species, six lures, a fish collection, and separate length/weight records.
- English and Traditional Chinese interfaces and animated README demos.
- Local fishing logic with no model calls or network requests.
- A plugin icon and a downloadable asset pack.

## Existing installations

Disable the previous fishing plugin in `/plugin` before installing this version, so both plugins do not handle the same turn. The renamed plugin uses a new store identity. Earlier records are not transferred automatically; retain the previous installation's data to keep those records.

## Compatibility and validation

The terminal currently displays text status and collection information. Pixel art requires a host surface with `Svg` support. Desktop interaction still needs a manual smoke test on the target host.

The plugin passes `claude plugin validate . --profile directory`, 16 automated mod tests, and asset validation covering 252 PNGs and 248 exact RLE round trips. The local directory validation does not establish acceptance by a directory's separate safety or policy review.
